# 🚀 Space Mission EDA

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a dataset containing information about space missions. The goal is to clean, analyze, and visualize the data to discover meaningful patterns and trends in space exploration.

The analysis focuses on mission outcomes, launch organizations, launch locations, mission costs, and other factors that provide insights into the history and development of space missions.

---

## 🎯 Objectives

- Understand the structure and characteristics of the dataset.
- Clean and preprocess the data.
- Handle missing and inconsistent values.
- Analyze mission success and failure rates.
- Identify organizations involved in space missions.
- Explore mission costs and launch trends.
- Analyze launch locations and mission outcomes.
- Create meaningful visualizations to communicate insights.

---

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook** – Data analysis and documentation
